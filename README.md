# UPI-Transaction-Analysis
End-to-end fintech analytics project focused on identifying transaction failure patterns, analyzing user behavior, and generating data-driven recommendations using Python, SQL, and Excel dashboards


## Business Problem

A digital payments company wants to understand transaction behavior, identify performance trends, analyze transaction success rates, and uncover business insights that can improve customer experience and payment reliability.


## Key Objectives

- Analyze transaction success and failure patterns
- Identify major failure reasons
- Evaluate merchant performance
- Analyze state-wise transaction trends
- Generate business recommendations


## Tools Used

- Python
- SQL
- Microsoft Excel


## Dataset

The project uses a realistic UPI Transaction Insights Dataset containing transaction timestamps, merchant categories, payment modes, transaction amounts, location types, and transaction success status.

Dataset Size:
- 500+ UPI Transactions
- Multiple Merchant Categories
- Multiple Payment Modes
- Transaction Success Indicators


  # Key KPIs

- Transaction Success Rate
- Transaction Failure Rate
- Gross Merchandise Value (GMV)
- Merchant Performance
- State-wise Transaction Volume
